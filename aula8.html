O que eu aprendi

1. Qual a diferença entre JavaScript externo, interno e inline?

O JavaScript externo fica em um arquivo separado e pode ser utilizado em várias páginas do site. O JavaScript interno fica dentro da própria página HTML, na tag script. Já o JavaScript inline é colocado diretamente em um elemento HTML, como em um botão. Para um programa com 200 linhas utilizado em várias páginas, escolheria o arquivo externo, pois facilita a organização e a manutenção, assim como acontece com o CSS externo.

2. Como funcionam os componentes e as propriedades?

Os componentes permitem reutilizar partes da interface sem precisar repetir todo o código. No catálogo da AgroFeira, cada produto pode ser representado por um componente próprio, assim como o componente Square utilizado no tabuleiro. As propriedades, chamadas de props, permitem enviar informações diferentes para cada componente, como nome, preço e imagem do produto.

3. Qual a diferença entre props e state?

As props são informações recebidas pelo componente, enquanto o state armazena informações que podem mudar durante a utilização da página. No componente Product, as informações do produto podem chegar por meio das props, enquanto o estado controla alterações feitas pelo usuário. Quando apenas dois produtos mudam após um clique, isso acontece porque somente os componentes que tiveram seus estados atualizados precisam refletir aquela alteração. Na AgroFeira, esse comportamento pode ser utilizado em produtos do catálogo, como a barra de chocolate e o cheiro-verde.

4. Qual decisão de estilo foi tomada para o projeto?

Para a AgroFeira, escolheria manter uma folha de estilos própria, pois ela permite personalizar as cores, fontes, espaçamentos e a identidade visual do projeto. O Bootstrap poderia acelerar a construção das páginas, enquanto o Tailwind oferece classes utilitárias para estilização. Minha decisão poderia mudar caso o projeto precisasse de um desenvolvimento mais rápido ou de componentes prontos. Durante os passos da atividade, foi possível perceber como os componentes React organizam a interface e como o CSS pode ser aplicado para manter a aparência do projeto.
