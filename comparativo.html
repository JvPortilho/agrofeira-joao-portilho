1. Introdução

Nesta atividade, foram comparadas duas versões do catálogo AgroFeira: uma desenvolvida com CSS próprio e outra utilizando o framework Bootstrap.

O objetivo foi observar as diferenças de responsividade, personalização, organização do código e desempenho das duas implementações.

2. Responsividade

A versão Bootstrap utiliza classes responsivas para organizar os produtos em diferentes tamanhos de tela.

Em 360 pixels, os cartões são apresentados em uma coluna. Em 768 pixels, passam a ocupar duas colunas. Em 1200 pixels, a organização permite três colunas de produtos.

3. Personalização do Bootstrap

Para aproximar a aparência do Bootstrap da identidade visual do AgroFeira, foram utilizadas cores semelhantes às presentes na versão desenvolvida com CSS próprio.

Personalização das cores

A personalização dos botões utiliza variáveis específicas do componente, como --bs-btn-bg e --bs-btn-hover-bg.

4. Comparação de desempenho

Foram realizados testes utilizando as ferramentas Network e Performance do Google Chrome DevTools.

Os resultados mostram que ambas as versões apresentaram tempos baixos de carregamento. A versão Bootstrap registrou LCP médio de 140 ms, enquanto a versão com CSS próprio apresentou média de 170 ms.

Essa diferença não significa que o Bootstrap seja sempre mais rápido, pois os resultados também dependem dos recursos carregados, do cache e das condições de cada teste.

5. Análise da rede

Na aba Network, foram observados os arquivos carregados e a quantidade de dados transferidos pelas duas versões do catálogo.

6. Análise do LCP

O Largest Contentful Paint (LCP) mede quanto tempo o maior elemento visível da página leva para ser renderizado.

Foram realizadas cinco medições em cada implementação para comparar os resultados.

A versão Bootstrap apresentou os seguintes resultados de LCP: 260 ms, 110 ms, 110 ms, 110 ms e 110 ms.

A média foi de 140 ms e a mediana de 110 ms. O CLS permaneceu em 0,00 nas cinco medições.

7. Vantagens e limitações

CSS próprio

O CSS próprio oferece maior liberdade para desenvolver a identidade visual do projeto. Entretanto, exige mais trabalho na criação e manutenção dos componentes responsivos.

Bootstrap

O Bootstrap facilita a criação de grades, cartões e componentes responsivos por meio de classes prontas. Por outro lado, pode exigir personalizações adicionais para manter a aparência desejada.

8. Conclusão

A atividade permitiu comparar duas formas de desenvolver a interface do AgroFeira. O CSS próprio oferece maior controle sobre a aparência e a organização visual, enquanto o Bootstrap facilita a construção de layouts responsivos com componentes prontos.

Nos testes realizados, as duas versões apresentaram bons resultados de desempenho. A escolha entre elas depende das necessidades do projeto, do nível de personalização desejado e da facilidade de manutenção.
