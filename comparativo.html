Comparativo de Responsividade e Desempenho

Início Catálogo CSS Catálogo Bootstrap Comparativo

1. Introdução

Este comparativo apresenta os testes realizados no projeto AgroFeira, desenvolvido para divulgar produtos de agricultores e produtores da região de Paragominas.

O objetivo foi analisar o comportamento responsivo do catálogo e comparar o desempenho de duas implementações: uma desenvolvida com CSS próprio e outra utilizando o framework Bootstrap.

2. Teste de responsividade em 360 px

O primeiro teste foi realizado simulando a largura de 360 pixels, semelhante à tela de um smartphone.

Foi observado como os elementos do catálogo, os botões, as imagens e o menu se adaptaram ao espaço disponível.

3. Teste em 1200 px antes dos ajustes

Nesta etapa foi analisada a apresentação do catálogo em uma largura de 1200 pixels, antes das alterações nas regras de estilo.

4. Ajustes no CSS e resultado

Foram analisadas as regras de estilo relacionadas aos botões e à organização dos elementos da página.

Após os ajustes, foi realizado outro teste na mesma largura de 1200 pixels para observar o resultado visual.

5. Análise da rede

Na aba Network do Chrome DevTools, foram observados os arquivos carregados, a quantidade de requisições e o volume de dados transferidos pelas duas versões do catálogo.

Versão com Bootstrap

A comparação permite observar que as duas versões carregam os recursos necessários para apresentar o catálogo. A versão Bootstrap também utiliza arquivos do framework, enquanto a versão autoral utiliza os estilos desenvolvidos especificamente para o projeto.

6. Análise do LCP

O Largest Contentful Paint (LCP) mede o tempo necessário para renderizar o maior elemento de conteúdo visível da página.

Foram realizadas medições utilizando a aba Performance do Chrome DevTools.

Observação: Os valores apresentados correspondem a medições específicas registradas durante os testes. Os resultados podem variar conforme o cache, a conexão, o dispositivo e as condições de execução. Os valores de rede e LCP não representam necessariamente a mesma execução.

8. Conclusão

A realização dos testes permitiu compreender melhor como diferentes formas de estilização podem influenciar a organização visual e o desempenho de uma página web.

O catálogo desenvolvido com CSS próprio oferece maior controle sobre a identidade visual e as regras de responsividade. Já a versão Bootstrap facilita a construção de componentes e a organização do layout por meio de classes prontas.

Nas medições selecionadas, a versão Bootstrap apresentou valores menores de dados transferidos, tempo de carregamento e LCP. Entretanto, esses resultados isolados não são suficientes para afirmar que uma abordagem será sempre mais rápida do que a outra.

A atividade contribuiu para o aprendizado sobre responsividade, análise de rede e métricas de desempenho, utilizando ferramentas disponíveis no navegador.
